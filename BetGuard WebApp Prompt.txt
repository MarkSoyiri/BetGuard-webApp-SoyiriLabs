PROJECT: BetGuard — Responsible Betting Companion Web App
=========================================================================
Create a high-fidelity, polished single-page web application called
"BetGuard" from scratch. It is a PROOF OF CONCEPT / companion app that
helps people bet responsibly. It is NOT a betting platform — there is no
real money, no real betting, no backend, no database server, no auth
server, and no external API. Everything runs client-side and persists in
localStorage.

=========================================================================
1. WHAT THE APP DOES (Product Summary)
=========================================================================
BetGuard lets a user:
- Track every bet they place (platform, sport, amount, win/loss, notes).
- Set a monthly betting budget in Ghana Cedi (GH₵) and see live progress.
- Create savings goals and move money "saved from betting" into them.
- Complete daily/weekly/monthly self-control challenges and earn badges.
- Take a risk assessment quiz that produces a Low/Medium/High risk score.
- Read educational articles and pass a financial-literacy quiz.
- Chat with a rule-based "AI Coach" that answers questions about their
  own betting data.
- Share posts and comment in a community feed (demo only).
- View rich, animated statistics and charts (Recharts).
- Earn/unlock achievements and read in-app notifications.
- Toggle light/dark theme, update their profile, and (as demo admin)
  manage "platforms" (CRUD on static demo entries).

Currency is Ghana Cedi (GH₵) and all demo data uses Ghanaian names and
context. Copy is encouraging, non-judgemental, and responsible-gambling
focused.

6. STATE MANAGEMENT + PERSISTENCE
=========================================================================
localStorage keys all prefixed "betguard:" (see utils/storage.ts:
readStorage/writeStorage/removeStorage/clearAllStorage/exportAllStorage/
importAllStorage). Persistence hook:

  usePersistedState<T>(key, initial):
    useState(() => readStorage(key, initial));
    useEffect(() => writeStorage(key, state), [key, state]);

Contexts (provider order matters):
  ThemeProvider   -> 'theme'        ('light'|'dark', default 'light')
  ToastProvider   -> in-memory only (not persisted), max 5 toasts,
                     auto-dismiss 3.8s, top-right, framer-motion spring.
                     toast(message, type='success').
  UserProvider    -> 'user' (UserProfile|null), 'authed' (boolean)
  BudgetProvider  -> 'budget' (number, default 600)
  BetProvider     -> 'bets' (BetRecord[], default generateDemoBets())
  GoalProvider    -> 'goals' (SavingsGoal[], default sampleGoals())
  AchievementProvider -> 'achievements' (Achievement[], sampleAchievements)
  NotificationProvider -> 'notifications' (AppNotification[],
                         sampleNotifications; unreadCount derived)
  CommunityProvider -> 'posts' (CommunityPost[], samplePosts())

Key context API:
  Bet:        bets, addBet(bet) -> BetRecord, updateBet, deleteBet, resetBets
  Budget:     monthlyBudget, setMonthlyBudget(clamped >= 0)
  Goal:       goals, addGoal, contribute(id, amount) [clamps at target],
              updateGoal, deleteGoal, resetGoals
  Achievement: achievements, unlockedCount, unlock(id)->boolean,
              addAchievement(title, desc, icon) [dedupes by title,
              always unlocked], resetAchievements
  Notification: notifications, unreadCount, addNotification(title,msg,type),
              markRead, markAllRead, removeNotification, clearAll,
              resetNotifications
  Community:  posts, addPost(post) [sets id, authorId:'me', likes:0,
              liked:false, comments:[], date:now], deletePost(id),
              toggleLike(id), addComment(postId, author, content),
              resetPosts
  User:       profile, isAuthenticated, isAdmin, login(email,password)->bool,
              register(profile), logout, updateProfile(patch)
  Theme:      theme, toggleTheme, setTheme
  Toast:      toast(message, type)

Demo auth behavior:
  login(): any credentials accepted; if no existing profile, creates
  profile "Alex Mensah" with the entered email, isAdmin:true,
  notificationsEnabled:true, age 24, occupation Student, income 2500.
  register(): saves the submitted profile, sets isAdmin:true for demo,
  and marks authed. logout() just flips authed to false (profile kept).

12. KNOWN GOTCHAS / FIXES TO PRESERVE
=========================================================================
- MOBILE OVERFLOW: any multi-column CSS grid that renders on mobile MUST
  start with `grid grid-cols-1 ...` (e.g. `grid grid-cols-1 gap-5
  sm:grid-cols-2 xl:grid-cols-4`). Without the explicit first column
  (minmax(0,1fr)), a single implicit auto track sizes to max-content of
  long nowrap/truncate rows and causes horizontal overflow on small
  screens. Verified: all routes have scrollWidth == innerWidth at 390px.
- Dark mode requires BOTH the index.html anti-flash inline script AND
  ThemeContext applying/removing the class on mount + on change.
- Recharts: wrap in fixed-height div (h-64) + ResponsiveContainer.
- Lazy route components must use `.then((m) => ({ default: m.X }))`.
- Toast state must NOT be persisted (in-memory only).
- Achievement unlock() flips `unlocked`/`unlockedAt` when
  `a.unlocked` is false; pre-unlocked seed items carry unlockedAt.
